# Modern religious (interfaith) edition

This tree is for readers who **practice** a living religion — **Muslim, Hindu, Christian, Jewish, Buddhist, Sikh, Jain, Zoroastrian, Indigenous**, and others — and who want **one coherent alternate history** that **respects** their existing faith **without** asking them to **convert**, **rank** God(s), or **swap** creeds.

**Method:** **interpretation only.** The book proposes **how** overlapping myths, calendars, catastrophes, and archive politics might **fit together** if timelines were **compressed or duplicated** and **records** were **curated**. **Evidence** is **comparative**: parallel stories, parallel dates, parallel suspicions about **who kept the books**.

**Editorial source:** adapt from **`content/`** (canonical timeline) as the technical spine; align voice with **docs/BOOK_EDITIONS_PLAN.md** (Modern religious edition and Shared religious-editions sections). New chapters: mirror paths under this tree, then apply interfaith passes (rotate examples, avoid supersessionism).

**YAML:** use `edition: modern-religious` on each file (mirror **`canonical_path`** like other editions).
