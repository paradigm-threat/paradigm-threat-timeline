# Content editions (print-oriented)

The project has **two** book products (see **docs/BOOK_EDITIONS_PLAN.md**):

1. **Definitive (default) edition** — **`../content/`**: canonical timeline; drives the site and `events.json`. This is also the **educational** product: **science-full**, skeptic-facing prose; **`docs/TIMELINE_FAQ.md`** and **`docs/FEEDBACK.md`** guide editorial priority only — they are **not** printed in the book.
2. **Religious edition** — this folder, **`modern-religious/`**: interfaith, interpretation-only, science-light adaptation of (1). Pilot: **`00.*`**, **`01.*`**.

**In `content-editions/`:** only **`modern-religious/`**. There is **no** separate Jewish/Zionist tree; Jewish-readership guardrails live inside the **religious** edition plan.

See **[docs/BOOK_EDITIONS_PLAN.md](../docs/BOOK_EDITIONS_PLAN.md)** for guardrails, workflow, and open questions.
