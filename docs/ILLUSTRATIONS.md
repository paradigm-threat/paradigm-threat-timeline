# Timeline Illustrations Plan

This document outlines the illustration plan for each chapter. Illustrations fall into two categories:

- **SVG diagrams** — Created in-repo: greyscale, book background (#f5f4f0), short height (~180–300px for book page). Include key/legend when multiple labeled elements.
- **Artist/CGI placeholders** — TODO for commissioned work: narrative scenes, human figures, atmospheric art.

---

## Conventions

- **Book page size**: 6″×9″; illustrations should be wide horizontal (aspect ~3:1), height kept short.
- **SVG background**: `#f5f4f0` (book cream).
- **SVG style**: Greyscale for diagrams; text dark (#111–#444), strokes clear.
- **Key table**: Required when diagram has multiple labeled elements/symbols.
